# 🛒 SmartCart

**SmartCart** is a responsive e-commerce shopping cart web application built using **HTML, CSS, and JavaScript**.

The project focuses on practicing JavaScript **DOM Manipulation, Events, Arrays, Objects, and Dynamic UI Rendering** while creating a real-world shopping experience.

---

## 🚀 Features

* 🛍️ Dynamic product listing
* 🔍 Product search interface
* 🏷️ Product category filters
* 🛒 Add products to cart
* 🔢 Dynamic cart item count
* 📱 Responsive design
* 🎨 Modern and clean user interface
* ⚡ Dynamic DOM manipulation
* 🖱️ JavaScript click events
* 📦 Product data using JavaScript objects and arrays

## 🎯 Current Functionality

Products are stored as JavaScript objects:

```javascript
const products = [
    {
        id: 1,
        name: "Wireless Headphones",
        price: 1499,
        category: "electronics"
    }
];
```

Products are dynamically displayed using DOM manipulation.

The **Add to Cart** functionality uses:

```javascript
event.target
dataset.id
find()
push()
```
